# Divyanshu Dubey — Editorial Portfolio

A premium, editorial-style portfolio website built for a **Data Science Engineer**. This project prioritizes sophisticated typography, intentional whitespace, and a "luxury Scandinavian minimalism" aesthetic inspired by Apple and modern Awwwards portfolios.

## ✨ Key Features
- **Editorial Typography**: A curated pairing of *Playfair Display* (Serif) and *Inter* (Sans-serif).
- **Luxury Minimalism**: A soft beige and gold color palette designed for professional, high-end personal branding.
- **Split-Screen Hero**: A distinctive layout featuring an artistic typography reveal and a premium profile showcase card.
- **Responsive & Accessible**: Fully optimized for all devices with seamless light and dark mode support via `next-themes`.
- **Fluid Animations**: Subtle, high-performance transitions powered by `framer-motion`.

## 🛠️ Tech Stack
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📝 Structure
- `src/components/sections`: Individual modular sections of the portfolio (Hero, About, Projects, etc.).
- `src/data`: Centralized data file (`index.ts`) for easy content updates.
- `src/app/globals.css`: Custom design system variables and editorial utility classes.
